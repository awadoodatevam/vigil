### 6.4 Serving the web application (AR-W-01)

Internal to `vigil.api` (not in `vigil.api.api`), one `@Configuration` class that:

- serves files under `classpath:/static/` at their paths;
- answers `GET` and `HEAD` for every other path that does not start with `/api/` or `/actuator/` and does not match a static file with `classpath:/static/index.html`, status 200, `Content-Type: text/html`, `Cache-Control: no-cache`;
- answers existing files under `/assets/` (Vite's content-hashed files) with `Cache-Control: max-age=31536000, immutable`, and a missing file under `/assets/` with 404 (no fallback);
- answers every other existing static file (Example: `/index.html`) with `Cache-Control: no-cache`;
- applies the fallback to `GET` and `HEAD` only; other methods on such paths get Spring's answer for a path without a handler, which this package does not test;
- leaves `/api/**` and `/actuator/**` to their own handlers (in this package: none, so they answer 404, not `index.html`).

### 6.8 `tools/trace.py` behaviour

- **Requirement ID**: a match of `\b(CTX|SL|PM|DM|SB|DD|DC|AR|BP)-[A-Za-z0-9]+(?:-[A-Za-z0-9]+)*\b`.
- **Spec rows**: in every `docs/packages/P-*.md` that is not a report (`P-##-report.md`), the table under the heading `## 4. Requirements built`: each row's first cell is one ID, its third cell is the proof, either `test` or text starting `checked by review:`. A row with a range, more than one ID, or another proof value is an error (printed with file and line; exit 1 with `--check`).
- **Test names**: the IDs at the start of (complete list): JUnit `@DisplayName("…")` strings in `*.java` under `app/src/test/` and `demo/*/src/test/`; the first string argument of `test(`, `it(` and `describe(` in `*.test.ts`, `*.test.tsx` under `web/src/` and `*.spec.ts` under `tests/e2e/`; the first word of the docstring of each `test_*` function in `test_*.py` under `tools/`, `demo/`, `dev/`, `deploy/local/` and `tests/`. Only the first word of the name counts, and it counts only when it is an ID.
- **`--check`**: exit 1, listing each spec row with proof `test` whose ID no test name starts with. Otherwise exit 0.
- **Without `--check`** (report for the checkpoint reviews): reads the IDs defined in `docs/*.md` and `docs/31-demo-data/README.md` (an ID is defined where it is the first cell of a table row, written as the whole cell, optionally in `**…**`); prints, grouped by prefix, the defined IDs of every prefix except `BP` that no test name starts with and that no row marks `checked by review:` in a spec whose report exists on `origin/main` (`git cat-file -e origin/main:docs/packages/P-##-report.md`; when the ref `origin/main` does not exist, the report file in the working tree counts). Exit 0.
