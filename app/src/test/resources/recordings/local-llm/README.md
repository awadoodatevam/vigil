# Recorded local model calls

The measured calls of one run of the local model spike SB-T-04, local model part (`spikes/providers/run.sh local-model`, package P-06), against `vigil-llm` on the GPU host: five SL-T-1 `/api/chat` calls of AR-G-23 with the storm incident built from `docs/31-demo-data/`. They are the payloads of the `local_model` connector tests of P-19. The model check (`/api/tags`), the warm-up call and the GPU check (`/api/ps`) are not recorded.

One file per call, `{n:04d}-{call}.json` (`n` from 1 in call order), `{call}` one of (in order) `chat-1` to `chat-5`. Each file is a JSON object with exactly these keys: `seq` (n); `call`; `started_at` (UTC, RFC 3339 with milliseconds); `duration_ms`; `request` (`method`; `url`, with the connector instance's address of `docs/31-demo-data/07-settings.yaml` in place of the real base address; `headers`, the headers the spike set, with `Authorization` and `x-api-key` values `<redacted>`; `body`, the text as sent); `response` (`status`; `headers`, only `Content-Type`; `body`, the text as received) or `null`; `error` (`null`, or the text of a connection failure or timeout). No file holds a secret: the spike checks every file before it writes it (P-06 spec Section 6.2). `url` is `http://${gpu_host_ip}:11434/api/chat`.
